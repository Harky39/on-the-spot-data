# On The Spot — data

Editable content and quote data for the two On The Spot websites.

- `car/content.json` — before/after showcase + gallery for https://harky39.github.io/on-the-spot-car-van-bodywork/
- `van/content.json` — same for https://harky39.github.io/on-the-spot-caravan-repairs/
- `quotes/index.json` — list of quote requests (summaries)
- `quotes/<id>.json` + `quotes/<id>/photo-N.jpg` — full quote details and photos

Edited through the staff admin panel at https://harky39.github.io/on-the-spot-admin/
